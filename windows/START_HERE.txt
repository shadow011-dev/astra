Shadow / Astra - Windows Source Package

1. Install Ollama for Windows: https://ollama.com/download (open it once)
2. In Command Prompt or PowerShell, run:
     ollama pull qwen3.5:4b
3. In this folder, double-click or run EITHER:
     run_app.bat        -> run the system-tray app straight from source
     build_app.bat      -> build dist\Astra\Astra.exe + Astra-win-x64.zip to share with friends

Karna hotkey: Alt+K (local Ollama).
Arjuna hotkey: Alt+M (OpenRouter; tray icon -> Settings).
Arjuna + Gemma 4 31B: hold Alt and press M and K together (OpenRouter, image analysis).
LED blinks: 1=A 2=B 3=C 4=D 5=E 6=F, 10 fast flickers = error.
One-word-answer questions: click-through popup top-right for 2s, no LED.

Note: defaults are Alt+K / Alt+M / Alt+M+K. Edit %USERPROFILE%\.shadow\config.json to customize them; restart Astra after editing.
