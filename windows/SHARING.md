# Sharing Astra with friends (Windows)

## You (builder) - once per version
Run `build_app.bat` in Command Prompt.
This makes `Astra-win-x64.zip`. Send that zip to friends.

## Friend (user) - one-time setup
Needs: Windows 10 or Windows 11 (64-bit), 8 GB RAM or more, ~5 GB free disk.

1. Install **Ollama** from https://ollama.com/download and open it once.
2. Unzip `Astra-win-x64.zip` into a folder and run `Astra.exe`. Keep the extracted `Astra` folder structure intact; do not move the EXE out of its folder.
3. Look for the **Astra** icon in the Windows system tray (bottom-right, near the clock; click `^` if hidden). It will offer to download the AI model (~3.4 GB). Click OK.
4. Right-click the tray icon -> **Test LED** to blink the Caps Lock light 3 times.
5. Default hotkeys: **Alt+K** (Karna), **Alt+M** (Arjuna), and **Alt+M+K together** (Gemma 4).
